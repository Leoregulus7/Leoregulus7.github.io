Description

HAITAO (Highly Advanced Intelligent Task Assistant Operations) est un bras robotique SCARA capable d'être commandé via une application, des gestes de la main et pouvant reconnaître des marqueurs et des objets.

Objectif
  • Une application Python permettant à l'utilisateur de définir une configuration et d'obtenir la position correspondante.
  • Une modélisation cinématique directe et inverse du mouvement du "End Effector".
  • La conception 3D des pièces mécaniques et de la structure du robot.
  • La reconnaissance de marqueurs ArUco pour adapter le placement des objets.
Technologies
Python Arduino Uno C++ Vision par ordinateur SolidWorks Impression 3D
Méthodologie

L'application Python calcule les positions et commande le robot. Le robot est piloté par un Arduino Uno équipé de deux moteurs pas-à-pas pour les axes et d'un servo-moteur avec électroaimant pour saisir ou relâcher des objets métalliques.
